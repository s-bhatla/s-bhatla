### Built things

**[JiraAgent](https://gitlab.battleofminds.net/sidharth.bhatla/issue-solver)** — Autonomous bug resolver. Drop in a Jira ticket and a codebase, get back a reviewed diff. LangGraph state machine + RAG-powered code search + vision parsing for screenshots + human-in-the-loop approval. Does the detective work, not just the typing.

**[NextB](https://github.com/s-bhatla/NextB)** — WhatsApp automation for keeping relationships alive without losing yourself to your phone. Claude generates personalized messages per contact; APScheduler fires them with natural-feeling randomness; guardrails prevent it from becoming that one friend who texts too much.

**[Sebas](https://github.com/s-bhatla/sebas)** — Personal AI assistant with a SQLite backbone. Todos, habits, Google Calendar — accessible via CLI or Discord DM. Runs on Groq.

**[ShiCity](https://github.com/s-bhatla/ShiCity-backend)** — Communal responsibility app for crowdsourced local issue reporting. Image sharing, heatmap generation, and the quiet hope that people care.

**[StoryChain](https://github.com/s-bhatla/StoryChain)** — Collaborative anonymous storytelling game. Built in Go because it deserved to be fast.

**[pubsub-http](https://github.com/s-bhatla/pubsub-http)** — Lightweight HTTP message broker using Go Fiber and a clean JSON protocol.
